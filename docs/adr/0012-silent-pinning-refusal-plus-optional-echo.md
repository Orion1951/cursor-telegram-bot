# Silent pinning refusal with optional refusal echo later

MVP explicit operator pinning drops unauthorized Telegram senders locally without emitting bot replies—minimizing feedback loops for scanners while still logging breadcrumbs for forensic review. Should inbox noise escalate, bridges may selectively enable a deferred, throttled one-shot refusal echo before returning to silence, but gratuitous conversational refusals per update were rejected upfront as counterproductive rate-limit amplifiers.
