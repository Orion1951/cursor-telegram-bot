# Monolithic workstation bridge repo first

Ship the TypeScript bridge as one cohesive npm-style package spanning long polling ingestion, explicit operator pinning hooks, manifests, and annex scaffolding so MVP desktop-tethering stays fast to evolve. Deferred package splintering may arrive later whenever publish-worthy surfaces or distinct cloud executors materially benefit from narrower modules—deferring prematurely avoided ceremony before tracer slices hardened.
